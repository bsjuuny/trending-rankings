AI SLM Integration

형태소 분석기 v3.0 엔진에 소형 언어 모델을 결합하여 자가 학습형 트렌드 시스템을 구축하는 방법입니다.

🚀 1. Ollama 설치 및 모델 준비

SLM을 로컬에서 구동하기 위해 가장 효율적인 도구인 Ollama를 사용합니다.

Ollama 설치: Ollama 공식 사이트에서 OS에 맞는 버전을 다운로드하여 설치합니다.
한국어 특화 모델 다운로드: 터미널에서 아래 명령어를 실행하여 Bllossom 모델을 내려받습니다. 
ollama pull bllossom:8b
서버 가동 확인: http://localhost:11434가 정상적으로 활성화되었는지 확인합니다.

💡 2. 하이브리드 연동 아키텍처

모든 문장을 AI로 분석하지 않고, 고도화된 3.0 엔진과 AI를 적절히 배분하여 속도와 정확도를 모두 잡습니다.

⚡ 규칙 기반 분석 (Fast)

일반적인 문장은 KoreanNLP 3.0이 즉시 처리하여 대시보드 속도를 유지합니다.

🧠 AI 기반 보충 (Deep)

분석이 모호하거나 신조어가 의심되는 경우만 SLM을 호출하여 사전을 업데이트합니다.

🛠 3. 자동 사전 학습 코드 (Example)

아래는 수집된 텍스트에서 AI가 신조어를 추출하여 nlp_feedback.json에 자동으로 저장하는 로직 예시입니다.

// AI를 통한 신조어 추출 예시 (Node.js)
async function discoverNewWords(text) {
    const response = await fetch('http://localhost:11434/api/generate', {
        method: 'POST',
        body: JSON.stringify({
            model: 'bllossom:8b',
            prompt: `다음 텍스트에서 유행어나 핵심 키워드 5개만 뽑아줘. 형식은 JSON 배열로: "${text}"`,
            stream: false
        })
    });
    const result = await response.json();
    return JSON.parse(result.response);
}

// 추출된 단어를 nlp_feedback.json에 반영
// (이 과정을 통해 분석기는 매일 밤 스스로 똑똑해집니다)

🌟 4. 기대 효과

이 구성을 통해 얻을 수 있는 비즈니스 가치입니다.

  • 비용 제로: 클라우드 AI API 비용 없이 무제한 분석이 가능합니다.
  • 독자적 사전 구축: 시간이 흐를수록 우리 서비스만의 특화된 키워드 데이터셋이 쌓입니다.
  • 트렌드 선점: 신조어가 뉴스에 나오기도 전에 커뮤니티 반응만으로 포착할 수 있습니다.
